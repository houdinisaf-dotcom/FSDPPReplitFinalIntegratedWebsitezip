---
name: PDP image pairing
description: Product detail galleries pair approved, variant-matched images while preserving their original composition.
---

When approved front and rear views exist for the exact selected colourway, use them as the full product-detail page pair. Preserve each product’s approved curated listing-hero order in the gallery and Quick View. If a matching pair is absent on the full detail page, keep both positions visible as clearly named pending placeholders; Quick View retains its existing single-image fallback. Never use concept boards or mismatched colourways, and preserve each photograph’s source proportions.

**Why:** Front/rear pairing supports the approved editorial product-page direction, while a curated listing hero can be part of a product’s approved presentation. FSD imagery mixes landscape lifestyle photographs and portrait detail views; arbitrary cropping or mismatched colourways can misrepresent a product. Explicit placeholders preserve the gallery layout without implying that unapproved photos are production assets.

**How to apply:** Match both full-detail views to the exact selected colourway, keep other approved views available in the gallery, retain the curated listing order for Quick View, and preserve each source image’s natural aspect ratio.

When an image is excluded only from product details, keep its catalogue mapping and source file intact; apply the exclusion at the detail-gallery boundary so other approved surfaces are unchanged.

**Why:** A global image filter can unintentionally remove existing imagery from listings, collection cards, and other surfaces when only a detail gallery is unsuitable.

**How to apply:** Use a detail-specific image selector for narrow gallery holds, and retain the original product-image data until replacement assets are approved.

For multi-colour products, an unlabelled product-detail photograph is not automatically colour-neutral. Only include a detail across variants when the source metadata explicitly marks it neutral; otherwise omit it from the selected gallery and retain a labelled pending slot.

**Why:** An unassigned close-up may visibly show one colourway and misrepresent other variants if treated as generic.

**How to apply:** Require an explicit neutral marker or an exact selected-colourway mapping for multi-colour galleries. Do not infer neutrality from a generic filename or description.
