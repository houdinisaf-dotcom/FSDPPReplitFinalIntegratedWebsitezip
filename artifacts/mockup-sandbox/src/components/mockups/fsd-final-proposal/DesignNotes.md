# FSD final proposal — design notes

**Direction:** Reference-led fashion-house editorial. A restrained black-and-white shopping surface, real product photography as the main event, Manrope for display and DM Sans for utility, with Champagne Gold used only for small marks and active states. Motion is brief, opacity/transform only, and reduced-motion is respected. No dark-gold sports UI, generated FSD/product media, or replaced logos.

**Source basis:** Supplied FSD master prompt and approved Stretch Your Story reference; `HomeHero.jsx`, `FsdNavigation.jsx`, `site-navigation.js` / `site-navigation.css`, `FsdSearchModal.jsx`, `product-detail-page.js`, `ProductDetail.jsx`, `data/products.js`, `master-products.json`, `clothing-lines.js`, `collection-image-config.js`, `collection-divisions.js`, `site-footer.js` / `site-footer.css`; extracted previews in `fsd-phase3`, `fsd-house`, and `fsd-catalogue`. The source records/preview folders were not edited. The shield and product/hero images copied to the sandbox are approved copies; source originals remain intact.

## Screen decisions

1. **Homepage — unchanged, faithful visual documentation:** Reproduces the current top status strip, complete FSD wordmark header and its existing navigation/search/country/bag controls, approved boxed hero, image crop, and exact headline, supporting copy, and CTA. No redesign or layout alternative is proposed. Components inspected: `HomeHero.jsx`, `FsdNavigation.jsx`, `site-navigation.js` / `site-navigation.css`, `showroom.css`, and `homepage-phase3.css`. The isolated preview uses the approved source logo and the existing approved hero-image copy.
2. **SHOP mega-menu — unchanged, faithful open-state documentation:** Shows the actual SHOP mega-menu open over the same approved homepage and header. The live `FsdNavigation` markup, `createNavigationModel`, and `site-navigation.css` were inspected and used to retain the existing six primary labels, exact SHOP group/subcategory hierarchy, default selection, feature treatment, and catalogue destination. No menu level, collection, image, layout, or styling has been invented; this is a visual preview of the existing approved UI, not an alternative or production implementation.
3. **Women’s AEROFORGE — intent:** Introduce the collection with editorial breathing room and catalog honesty. Reference fit: spacious light shopping surface and image-led cards. Unchanged: four actual records (18, 38, 39, 51), names, confirmed prices, simple filtering. Proposed refinement: understated collection title and compact image availability filters. Components: `ClothingGalleryEditorial.tsx`, `ProductCard.jsx`, `clothing-lines.js`, `collection-image-config.js`. Approved image: ID 18 only, White / Green front product image. Explicit missing data: no AEROFORGE collection banner; product-image groups for IDs 38, 39 and 51 are missing. Those three cards use named `[ASSET PENDING]` treatment; ID 18 photographs are not reused for them. Risk: all other image groups remain pending.
4. **Desktop PDP — intent:** Bring the reference’s two-photo / narrow-panel composition directly to the confirmed tee. Reference fit: bright surface, large side-by-side front and back product views, narrow selectors panel. Unchanged: ID 18 title, £39.99, White / Green initial selection, all six true colourways, sizes S–XXL, source description and verified specifications/care. Proposed refinement: clearer size state and concise disclosure sections. Components: `product-detail-page.js`, `ProductDetail.jsx`, product media/size-guide data. Both exact square assets are available and remain square using `object-fit:contain`; other variants have mapped front images but no inferred back pairs. Risk: size-guide measurements are not available. Add-to-bag/checkout are visibly non-operational in this mockup.
5. **Mobile PDP — intent:** Let the two correct product views lead, with the selector stack and sticky action easy to reach. Reference fit: photography first, simple selectors, little decoration. Unchanged: ID 18 confirmed product data and mapped square imagery. Proposed refinement: single-column gallery with a bottom safe-area-aware disabled add bar; controls remain comfortably tappable. Components: `product-detail-page.js`, `ProductDetail.jsx`, current sticky add concept. Same two mapped White / Green square originals. Risk: size-guide measurements absent; sticky button is disabled and no bag interaction is claimed.
6. **Search & Quick View — intent:** Treat search as a quiet catalogue tool and Quick View as an anchored product state. Reference fit: minimal shopping chrome and genuine images. Unchanged: current search semantics (product, collection and brand story matching), genuine catalogue names/destinations, Quick View eligible ID 18 data. Proposed refinement: split search results from an inline product quick view for this review canvas. Components: `FsdSearchModal.jsx`, `catalogue-data.js`, `product-detail-page.js`, `ProductDetail.jsx`. Both White / Green product views available; other search results are text-first due to absent imagery. Risk: this is a static interaction proof; it does not connect to catalogue routing, bag APIs, or checkout.
7. **THE HOUSE — intent:** Present the six divisions as a credible, editorially ordered index without turning plans into claims. Reference fit: restrained type, generous spacing. Unchanged: six divisions, source item names, actual public paths and draft gates. Proposed refinement: one readable two-column hierarchy. Components: `site-navigation.js` (`makeHouseGroups`), `data/house-page-readiness.js`, `collection-divisions.js`; extracted `fsd-house` previews. No new imagery required. Risks: Our Story, flagships and Investor Relations remain gated; promotions, global initiatives and community descriptions retain source disclaimers and are not described as operational where not supported.
8. **Footer — intent:** Close with the approved shield and a small, legible link architecture. Reference fit: composed editorial spacing; dark footer is required brand signature. Unchanged: genuine explore/support/legal links and disabled newsletter state/copy. Proposed refinement: clearer brand / explore / support / newsletter columns and a quiet legal baseline. Components: `site-footer.js`, `site-footer.css`, `FsdLogo`. Approved shield copy available. Risk: no social links or contact details are invented; newsletter submission remains disabled.
