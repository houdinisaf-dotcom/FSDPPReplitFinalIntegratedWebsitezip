# FSD Website — Phase 1: Luxury Motion & Ambient UI

Review the existing FSD website before making changes. The current website already has a strong visual identity and established components. This task is to enhance its interaction quality, not redesign it.

## Preserve

- Existing black, graphite and champagne-gold visual identity.
- Current homepage hero and editorial content.
- All product imagery, product data and collection structures.
- Existing FSD Apparel, Bio-Lab, Hardware and Global sections.
- Current floating collection panels and category filters.
- Existing navigation behaviour, except where transitions are improved.
- Checkout and publishing restrictions.

## Implement

### A. Shared motion tokens

Create reusable motion settings for the website:

- Microinteraction: approximately 150–220 ms.
- Panel transitions: approximately 250–350 ms.
- Section reveal: approximately 400–650 ms.
- Use smooth, restrained easing curves.
- Respect prefers-reduced-motion.

### B. Homepage

Add a tasteful initial reveal to the hero image, heading and CTA.

Introduce scroll-triggered reveals to editorial sections using Intersection Observer, ensuring content remains visible if JavaScript or animation fails.

Avoid aggressive parallax and excessive animation.

### C. Floating collection panels

Improve panel open/close transitions using opacity and transform.

Introduce subtle staggered appearances for category filters and product cards.

Keep the panels stable, accessible and scrollable. Do not introduce automatic page scrolling.

### D. Ambient champagne lighting

Apply soft, low-opacity champagne illumination to active navigation items, selected category filters and featured cards.

Avoid neon glows, thick gold borders and excessive shadows.

### E. Product cards

Add restrained hover elevation, image scaling and CTA transitions.

Ensure touch devices receive equivalent feedback without requiring hover.

### F. Performance and accessibility

Use transform and opacity for motion wherever possible.

Avoid unnecessary heavy animation libraries.

Prevent layout shifts and ensure smooth mobile performance.

Maintain keyboard navigation, focus visibility and reduced-motion support.

## Workflow

1. Audit the existing components and animation libraries.
2. Identify safe, reusable enhancement points.
3. Implement the shared motion system.
4. Apply enhancements to the homepage and floating collection panels.
5. Test desktop and mobile layouts.
6. Report all modified files and any performance concerns.

Do not change product content, pricing, logos, checkout status or deployment settings.

Do not begin Bio-Lab dashboard implementation in this phase.

The desired result is a polished, cinematic luxury-performance experience that feels precise, fluid and intentionally restrained.
