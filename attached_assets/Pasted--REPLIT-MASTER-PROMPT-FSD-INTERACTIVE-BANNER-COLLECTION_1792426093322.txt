# REPLIT MASTER PROMPT — FSD INTERACTIVE BANNER & COLLECTION NAVIGATION REDESIGN

## PROJECT OBJECTIVE

Redesign the existing FSD Fitness & Self Defence website's homepage collection banners and product discovery experience.

**IMPORTANT: Do not rebuild the entire website. Do not remove existing assets, product information, images, or established branding.**

The current website has a premium black, gold and white design, with the headline:

**BUILT FOR THE DRIVE WITHIN.**

Maintain this overall identity.

The issue is that the current website displays too many large banners and product visuals stacked vertically. This makes the experience feel like a long scrolling presentation rather than a sophisticated, interactive luxury brand website.

I want to replace this with a premium interactive banner system featuring:

- Large cinematic category banners.
- Liquid-glass borders and translucent overlays.
- Subtle metallic gold accents.
- Animated category selection.
- Expandable pop-up collection menus.
- Smooth transitions between product divisions.
- Interactive product subcategory cards.
- A clean, controlled homepage layout.
- Mobile-responsive interactions.

The overall experience should feel like a combination of a luxury performance brand, a premium automotive configurator and a futuristic technology showroom.

## 3. LIQUID-GLASS BANNER DESIGN

Every main collection banner must have a premium liquid-glass visual treatment.

Use:
- Translucent glass surfaces.
- Backdrop blur.
- Subtle gold-tinted glass borders.
- Soft edge highlights.
- Dark reflective overlays.
- Rounded corners of approximately 20–28px.
- Smooth hover transitions.
- Elegant gold directional arrows.
- Very subtle parallax or light movement.

The glass effect must not make the text difficult to read.

Avoid excessive neon, cartoon effects or bright gradients.

The appearance should remain sophisticated, cinematic and expensive.

Suggested design tokens:

- Background: #08090B
- Secondary Background: #111216
- Metallic Gold: #C9A66B
- Highlight Gold: #E3C68C
- Primary Text: #F5F5F5
- Muted Text: #A8A8AD

Use these as starting points, while respecting the existing site's design tokens.

## 4. ANIMATED POP-UP CATEGORY EXPERIENCE

When a user clicks a main category banner:

1. The selected banner responds with a subtle gold glow.
2. A translucent dark overlay appears over the page.
3. A large liquid-glass collection panel opens smoothly.
4. The category title animates into view.
5. Subcategory cards appear with a staggered transition.
6. The user can select a subcategory without immediately navigating away from the homepage.
7. Selecting a subcategory updates the content inside the panel.
8. A dedicated "Explore Collection" button can then navigate to the relevant collection page.

Use a premium animation duration of approximately 250–450 milliseconds.

The modal must support:
- Close button.
- Escape key.
- Click outside to close.
- Keyboard navigation.
- Focus management.
- Scroll locking while open.
- Mobile full-screen presentation.
- Reduced-motion accessibility preferences.

Do not create multiple overlapping pop-ups.

Use a single reusable collection modal component driven by structured category data.

## 5. INTERACTIVE PRODUCT SUBCATEGORY DISPLAY

Inside each category pop-up, display elegant product cards.

Each card should contain:

- Product name.
- Product category.
- Short product description.
- Product development status.
- Optional product visual.
- "Explore Concept" or "View Details" action.

If a final product photograph is unavailable, use a tasteful branded placeholder.

**Do not automatically fill every card with CGI renders.**

The existing uploaded renders should remain available in the project asset library for future use.

Use statuses such as:
- Concept
- In Development
- Pre-Launch
- Coming Soon

Only use a status when supported by the project information.

No checkout functionality is required.

Do not add shopping carts, payment processing, fake reviews, false availability or fabricated release dates.

## 7. MOBILE EXPERIENCE

The mobile website must not simply shrink the desktop banners.

On mobile:

- Display category banners as large, premium stacked cards or a controlled swipeable carousel.
- Keep titles readable.
- Maintain comfortable touch targets.
- Open category selections in full-screen or bottom-sheet panels.
- Use smooth vertical scrolling inside the category panel.
- Keep the close button visible.
- Avoid heavy animation that affects performance.

The mobile design must feel intentionally designed, not like a compressed desktop layout.
