# PART 2 — THE APPROVED FSD PHASE 3 DESIGN

The following specification defines the intended result.

Use the original Phase 3 screen recording and screenshots as the primary visual reference where available.

## 2.1 Header

The approved header must have:

- Premium black/obsidian background.
- Official FSD master logo on the left.
- Minimalist luxury typography.
- Refined spacing.
- Champagne-gold hover and active accents.
- Smooth, restrained transitions.

### Approved primary navigation

- Collections
- Bio-Lab
- Hardware
- The House
- Private Access

The later replacement header containing Products, Our Story, Innovations, Design Library and VIP Access must not replace this approved navigation.

Existing routes associated with those pages may remain accessible elsewhere where appropriate.

## 2.2 Full-width mega-menu

The original navigation featured an elegant, full-width dropdown directly beneath the header.

It must:

- Overlay the page rather than push the content down.
- Use a dark graphite/obsidian background.
- Have subtle champagne-gold borders and accents.
- Open smoothly.
- Support hover, click and keyboard interactions.
- Remain open when the pointer moves into the dropdown.
- Allow switching between navigation categories without unnecessary closing.
- Include a clear Close control.
- Close when Escape is pressed.
- Close appropriately when clicking outside.
- Avoid unexpected page scrolling.
- Respect reduced-motion preferences.

Do not replace this with static cards, conventional dropdown lists, ordinary navigation links or automatic scrolling.

## 2.3 Three-column layout

### COLUMN ONE — COLLECTION GROUPS

Display the relevant groups for the selected primary navigation category.

Use a vertical navigation list with refined champagne-gold highlighting.

The active group should be visually identifiable.

### COLUMN TWO — CONTEXTUAL SUBCATEGORIES

Display the subcategories associated with the selected group in Column One.

Changing the active group must update Column Two without navigating away from the page.

### COLUMN THREE — FEATURED EDITORIAL CONTENT

Display:

- An approved FSD product or collection image.
- Relevant collection heading.
- Short editorial description.
- Appropriate existing destination link.

The content should update when the selected collection or subcategory changes, where applicable.

Use existing approved imagery.

Do not invent replacement product images.

## 2.4 Navigation hierarchy

Preserve the existing confirmed collection taxonomy.

The system must support:

- FSD Apparel / Collections.
- FSD Bio-Lab.
- FSD Hardware.
- FSD Global and relevant House content.
- The House.
- Private Access.

Use the established product and collection data already present in the project.

Do not invent new categories or rename approved groups.

If exact historical submenu labels cannot be recovered, identify them for approval.
