# FSD WEBSITE — AEROFORGE IMAGE PACKAGE & PRODUCT INTEGRATION

## OBJECTIVE

Integrate the supplied FSD AeroForge Modest Activewear images into the existing website using the **same approved product presentation approach as the FSD Weighted Skipping Rope**.

This is an image-led product integration task, not a redesign.

The product imagery must be imported into the website's asset library and connected to the existing Phase 4 product catalogue.

## 1. PRESERVE THE EXISTING WEBSITE

Do not alter the approved:

- Homepage, header, footer or full-width interactive mega-menu
- Black, graphite and satin champagne-gold design system
- Product catalogue architecture, variant logic or existing collections
- Weighted skipping rope product experience
- Women's apparel, sports hijab or other approved product pages

Keep the new AeroForge collection in **DRAFT / PENDING APPROVAL**.

Do not activate checkout, payments or public publishing.

## 2. PRODUCTS

Create two distinct draft products:

**FSD AeroForge Modest Training Top**

A long-sleeve modest training tunic with a high neckline, quarter-zip opening, extended hem, side-slit detailing and thumbhole cuffs, following the supplied reference.

**FSD AeroForge Performance Joggers**

Coordinated tapered joggers with an elasticated waistband and cuffed ankles, following the supplied reference.

Present both products together as the **FSD AeroForge Modest Activewear Collection**.

Do not invent prices, inventory, fabric composition or performance certifications.

## 3. IMAGE PACKAGE — IMPORTANT

Use the exact uploaded reference imagery and prepared catalogue artwork.

The original AeroForge reference image is the visual authority for garment styling, proportions, detailing and branding.

The prepared catalogue artwork is a presentation reference and supporting asset.

Import all supplied files and create a documented asset manifest.

**Do not assume that a single composite image is equivalent to multiple independent product photographs.**

Where individual images can be safely extracted from the supplied artwork, prepare properly framed web assets without stretching, artificial recolouring or damaging the garment details.

If a required image cannot be extracted cleanly, mark it **PENDING ASSET APPROVAL**.

Never invent a missing rear view, close-up or product angle.

## 4. PRODUCT HERO — ONE IMAGE

Use one strong, full-size hero image for the AeroForge collection.

The hero should feature the complete coordinated tunic-and-joggers outfit, with a clean premium composition.

It should:

- Establish the product immediately
- Preserve the original clothing design
- Show the tunic and joggers clearly
- Avoid unnecessary text overlays
- Work across desktop and mobile
- Use the existing approved image treatment

**Hero headline:**

MOVE WITH CONFIDENCE.

**Supporting text:**

Modest coverage. Refined athletic design.

**CTA:**

EXPLORE AEROFORGE

The hero remains independent of the product's selected colour swatch.

## 5. PRODUCT PAGE — MATCH THE WEIGHTED SKIPPING ROPE APPROACH

Use the same restrained, premium interaction model already approved for the FSD Weighted Skipping Rope.

The product detail presentation must show:

**ONE LARGE MAIN PRODUCT IMAGE AT A TIME.**

Below or alongside it, provide a minimal selector for the available supporting views.

Selecting another view smoothly replaces the main image in the same position.

Do not display an enormous image grid.

Do not create 20–30 unnecessary gallery images.

Do not use the entire composite reference sheet as the main product photograph.

Supporting views should be limited to genuinely available assets, such as:

- Full outfit
- Tunic detail
- Joggers detail
- Collar / zip detail
- Thumbhole cuff
- Fabric / stitching detail
- Side or rear view, only where supplied

## 6. SIX COLOURWAYS

Provide these six colour options:

- Black
- Grey
- Navy
- Olive
- Mauve
- White

Use the existing Phase 4 colour-swatch component.

When a customer selects a colour:

1. The selected swatch becomes active.
2. The single main product image updates to the corresponding approved colour image.
3. The product name and selected colour remain synchronized.
4. The page does not jump, reload or scroll unexpectedly.
5. The hero image remains unchanged.

Do not use CSS filters to recolour the clothing.

If an approved standalone image is unavailable for a colour, retain the colourway in draft with a clear missing-asset status.

## 7. COLLECTION PAGE

Create a clean AeroForge collection landing page featuring:

- One premium campaign hero
- Two distinct product cards: Training Top and Performance Joggers
- A coordinated outfit presentation
- A six-colour selection experience
- Responsive layouts consistent with the existing FSD website

Do not replace the approved navigation or introduce a new collection-page design system.

## 8. PRODUCT CONTENT

**Collection name:** FSD AeroForge Modest Activewear

**Headline:** MOVE WITH CONFIDENCE.

**Description:**

"Discover the FSD AeroForge Modest Activewear Collection, where considered coverage meets contemporary athletic styling. Featuring a longline training top and coordinated joggers in six refined colourways, AeroForge brings a confident, cohesive look to your active wardrobe."

Use only image-supported garment details.

Mark material composition, sizing measurements, care instructions and performance claims pending verification until approved.

## 9. IMAGE OPTIMIZATION

- Preserve the original uploaded files.
- Create optimized web derivatives where appropriate.
- Use WebP or AVIF for supported web presentation.
- Retain high-quality source files separately.
- Maintain natural aspect ratios.
- Avoid cropping logos, garment hems, sleeves or jogger cuffs.
- Add meaningful alt text.
- Use lazy loading for supporting images, not the primary hero.
- Keep the main image container stable when changing views.
