# FSD — THE HOUSE OF PERFORMANCE
## REPLIT MASTER WEBSITE DESIGN & USER EXPERIENCE PROMPT

### PROJECT OVERVIEW

I want to refine my existing FSD Fitness & Self Defence website into a sophisticated international luxury performance brand experience.

The creative direction is:

**FSD — THE HOUSE OF PERFORMANCE**

Brand philosophy:

**Luxury in its expression. Performance in its purpose.**

Existing campaign statement:

**BUILT FOR THE DRIVE WITHIN.**

FSD should be presented as a luxury performance house combining premium fashion, technical apparel, combat sports, wearable technology, engineered fitness equipment and future flagship experiences.

The website should take inspiration from:

- **Apple:** Minimalism, precision, effortless interaction and elegant product presentation.
- **Nike:** Powerful editorial photography, athletic energy and clear collection discovery.
- **Luxury fashion houses:** Sophisticated typography, craftsmanship, restrained branding and generous whitespace.

Do not copy another brand's website.

The finished website must feel unmistakably FSD.

---

# PHASE 1 — AUDIT AND PRESERVE THE EXISTING WEBSITE

Before making any design changes:

1. Inspect the current Replit project.
2. Review the existing homepage, navigation, collection sections and product pages.
3. Identify current logo assets, banners, product images and existing routes.
4. Identify why clicking collection banners currently scrolls visitors further down the page instead of opening subcategory menus.
5. Identify duplicated banners, excessive scrolling and inconsistent layouts.
6. Preserve all existing source files and product data.
7. Create a safe backup or reversible checkpoint before implementation.

**Do not delete existing content or rebuild the website from scratch.**

Do not change existing product designs, clothing logos, hardware imagery, product names or packaging.

The website is still in development and must not be published.

# PHASE 2 — ESTABLISH THE OFFICIAL FSD WEBSITE COLOUR SYSTEM

Create a consistent website design-token system using the following proposed palette.

| Colour | Hex | Purpose |
|---|---|---|
| Obsidian Black | #090A0C | Primary luxury background |
| Graphite | #1A1C20 | Navigation, cards and panels |
| Champagne Gold | #C8AA72 | Brand accents and selected details |
| Porcelain | #F3F0E9 | Editorial contrast sections |
| Steel Grey | #8D929B | Supporting details and muted text |
| Soft White | #F7F7F5 | Primary text on dark backgrounds |

These colours are for website interface styling and must not recolour the original FSD logo or existing product images.

### Colour application

Use predominantly obsidian and graphite.

Introduce porcelain or warm off-white sections occasionally to create editorial contrast.

Use champagne gold sparingly for:

- Selected navigation states.
- Small decorative details.
- Premium CTA accents.
- Fine separators.
- Important brand highlights.

Do not make every heading, button or border gold.

Avoid excessive gradients, neon colours, thick metallic borders or constant glow effects.

The overall appearance must feel luxurious because of its restraint.

# PHASE 5 — INTERACTIVE SUBCATEGORY NAVIGATION

The current website relies too heavily on scrolling.

This must be corrected.

When visitors click a main navigation category or collection banner, they should be able to discover the relevant subcategories immediately.

Do not automatically scroll the page when a category is selected.

### Create two working design options

**OPTION A — Minimal Translucent Dropdown**

A refined navigation panel that expands beneath the header.

Features:

- Soft charcoal background.
- Subtle transparency.
- Generous spacing.
- Clear category headings.
- Smooth transitions.
- Minimal decoration.

**OPTION B — Floating Editorial Collection Panel**

A sophisticated floating panel with a restrained glass effect.

Features:

- Softly rounded corners.
- Minimal champagne accents.
- Elegant typography.
- Carefully arranged subcategories.
- Subtle background blur.
- Smooth opening and closing.

Avoid oversized bubbles, exaggerated liquid effects and unnecessary animation.

### Interaction requirements

- First click opens the category selector.
- Subcategories are clearly visible.
- Selecting a subcategory may reveal a short description and an Explore Collection action.
- Navigation occurs only when a destination is deliberately selected.
- The page must not jump or scroll unexpectedly.
- Visitors can close the menu with Escape, the close control or by clicking outside.
- The menu must be accessible by keyboard.

On mobile, use a clean responsive navigation sheet.

Use restrained animation, approximately 180–280 milliseconds.

Respect reduced-motion accessibility preferences.

**Show me both navigation prototypes before implementing either across the whole website.**

# PHASE 7 — COLLECTION BANNER DESIGN

The homepage must not become an endless stack of large promotional banners.

Use a limited number of high-quality editorial entry points.

Each banner should have:

- One strong image.
- One clear heading.
- Minimal supporting copy.
- One primary interaction.
- Consistent image proportions.
- Subtle hover feedback.
- Clean mobile cropping.

Create a reusable collection-banner component.

Where appropriate, use asymmetrical editorial layouts to create a luxury fashion-house atmosphere.

Avoid excessive carousels, repeated promotional graphics and decorative clutter.

The images should communicate the brand without requiring paragraphs of explanation.
